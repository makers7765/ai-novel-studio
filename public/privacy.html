隐私说明

更新日期：2026 年 11 月 20 日

重要提示：StoryForge 默认将小说项目保存在当前浏览器设备中。使用 AI 生成功能时，你主动提交的提示词、参考原文和所选小说资料会发送给你选择的 AI 服务商。

1. 我们处理哪些数据

  • 小说项目数据：作品名称、简介、大纲、世界观、人物、章节、记忆、时间线、素材和归档，默认保存在本机浏览器的 localStorage 中；本应用不提供账号登录或跨设备云同步。
  • 模型 API Key：你输入的 API Key 保存在当前浏览器会话的 sessionStorage 中，不写入小说备份。调用 AI 时，密钥会随请求发送至本网站的 /api/generate 服务端函数，再用于向你选定的模型服务商认证。
  • AI 请求内容：你填写的创作要求、参考原文及勾选的小说上下文会被转发给所选模型服务商，以生成回答。

2. 第三方 AI 服务

可选服务商包括 Google Gemini、Groq、OpenRouter，以及在部署环境中配置的 Cloudflare Workers AI。第三方服务商会按照各自的隐私政策、服务条款和数据保留规则处理请求内容。请在使用前阅读对应服务商的政策，不要提交密码、身份证件、支付信息或其他不应向第三方披露的敏感资料。

3. 数据保存与删除

本机小说数据会在你清除浏览器网站数据、卸载浏览器或更换设备时丢失。建议定期使用“导出备份”保存 JSON 文件。你可以在模型设置中清除本机 API Key 配置，也可以通过浏览器站点数据设置清除本机作品数据。导出文件由你自行保管。

4. 网站托管与技术日志

网站由 Cloudflare Pages 托管。托管服务可能依据其自身政策处理访问请求所需的技术信息，例如 IP 地址、请求时间和安全日志；具体以 Cloudflare 的适用政策为准。本应用代码未主动加入广告追踪或第三方行为分析脚本。

5. 未成年人及政策变更

若你未达到所在地区使用相关 AI 服务的最低年龄要求，请在监护人同意和当地法律允许的情况下使用。隐私说明可能随功能变化而更新，更新日期会同步调整。

6. 联系方式

隐私问题、数据请求或反馈，请通过项目维护渠道联系：StoryForge 项目反馈入口。正式公开上架前，运营者应补充真实主体名称和可长期使用的联系邮箱。
